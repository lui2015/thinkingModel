## 一、项目概述

### 1.1 产品愿景

打造一个**开放、实用、有趣**的思维模型知识库网站，将人类历史上最优秀的思维模型和认知框架整合在一起，通过通俗易懂的介绍、生动有趣的案例和清晰的使用指引，帮助用户快速理解并应用这些思维工具，提升决策质量和认知水平。

### 1.2 目标用户

| 用户类型 | 描述 |
|---------|------|
| 终身学习者 | 热衷自我提升、阅读成长类书籍的人群 |
| 职场人士 | 需要提升决策力、沟通力、领导力的管理者和从业者 |
| 学生群体 | 大学生及研究生，希望建立系统化思维框架 |
| 创业者/产品经理 | 需要多元思维模型辅助商业决策 |
| 内容创作者 | 需要思维框架来组织内容和观点 |

### 1.3 核心价值主张

- **不只是收藏，更是实战手册**：每个模型都配有真实案例和使用步骤
- **不只是文字，更是可视化体验**：用图解、图谱和交互让抽象概念具象化
- **不只是单个模型，更是思维体系**：帮助用户建立多元思维模型的组合拳
- **沉浸式主题体验**：支持多种视觉风格切换，适配不同场景和审美偏好

### 6.3 主题系统实现原理

```
@theme inline { ... }     ← Tailwind v4 注册 token（编译时）
:root { --color-xxx }     ← 默认主题值（运行时）
[data-theme="xxx"] { }    ← 各主题覆盖同名变量（运行时切换）
```

- `@theme inline` 注册固定默认值，让 Tailwind 生成 `bg-primary`、`text-text` 等工具类
- `:root` 和 `[data-theme]` 在运行时覆盖同名 CSS 变量
- 工具类底层引用 `var(--color-xxx)`，变量被覆盖后所有引用自动跟随
