# 思维模型库（Mental Models Hub）— 产品需求文档

> **版本**：v1.0  
> **日期**：2026-04-22  
> **状态**：初稿

---

## 一、项目概述

### 1.1 产品愿景

打造一个**开放、实用、有趣**的思维模型知识库网站，将人类历史上最优秀的思维模型和认知框架整合在一起，通过通俗易懂的介绍、生动有趣的案例和清晰的使用指引，帮助用户快速理解并应用这些思维工具，提升决策质量和认知水平。

### 1.2 目标用户

| 用户类型 | 描述 |
|---------|------|
| 终身学习者 | 热衷自我提升、阅读成长类书籍的人群 |
| 职场人士 | 需要提升决策力、沟通力、领导力的管理者和从业者 |
| 学生群体 | 大学生及研究生，希望建立系统化思维框架 |
| 创业者/产品经理 | 需要多元思维模型辅助商业决策 |
| 内容创作者 | 需要思维框架来组织内容和观点 |

### 1.3 核心价值主张

- **不只是收藏，更是实战手册**：每个模型都配有真实案例和使用步骤
- **不只是文字，更是可视化体验**：用图解和交互让抽象概念具象化
- **不只是单个模型，更是思维体系**：帮助用户建立多元思维模型的组合拳

## 二、内容体系

### 2.1 思维模型分类（参考"圈中的猫头鹰"、"思维有了模型"等账号）

| 分类 | 示例模型 | 说明 |
|------|---------|------|
| **决策思维** | 第二序思维、反转思维、决策矩阵、10/10/10 法则 | 帮助做出更好的选择 |
| **认知升级** | 第一性原理、心智模型、邓宁-克鲁格效应、确认偏误 | 识别认知盲区，突破思维局限 |
| **系统思维** | 飞轮效应、反馈回路、涌现效应、复利思维 | 理解复杂系统的运作规律 |
| **沟通表达** | 金字塔原理、SCQA 模型、非暴力沟通、故事思维 | 提升沟通效率和说服力 |
| **商业分析** | 波特五力、SWOT 分析、护城河理论、供需模型 | 商业环境分析和战略决策 |
| **学习成长** | 费曼学习法、刻意练习、能力圈、T 型人才模型 | 加速学习和个人成长 |
| **概率思维** | 贝叶斯思维、大数定律、均值回归、黑天鹅理论 | 在不确定性中做出理性判断 |
| **效率管理** | 帕累托法则（80/20）、艾森豪威尔矩阵、PDCA 循环 | 提升时间和精力管理效率 |
| **创新思维** | TRIZ、类比思维、逆向思维、奥斯本检核表法 | 激发创造力和创新方案 |
| **博弈思维** | 囚徒困境、纳什均衡、零和博弈、正和博弈 | 理解竞争与合作的本质 |

> 初期目标：收录 **50-80 个** 核心思维模型，后续持续扩展。

### 2.2 单个模型的内容结构

每个思维模型页面包含以下模块：

```
┌─────────────────────────────────────────┐
│  模型名称 + 一句话概括                      │
│  所属分类标签 + 难度等级（⭐~⭐⭐⭐）          │
├─────────────────────────────────────────┤
│  📖 通俗介绍                              │
│  用日常语言解释模型的核心思想，避免学术化       │
│  配合一张核心图解/示意图                     │
├─────────────────────────────────────────┤
│  🎯 一个关键洞察                           │
│  这个模型最核心、最颠覆的观点是什么             │
├─────────────────────────────────────────┤
│  📚 有趣案例（2-3个）                      │
│  - 生活场景案例（贴近日常）                   │
│  - 商业/历史经典案例                        │
│  - 反面案例（不用会怎样）                    │
├─────────────────────────────────────────┤
│  🛠️ 使用指引                              │
│  - 适用场景：什么时候该用这个模型               │
│  - 使用步骤：1, 2, 3... 具体操作             │
│  - 常见误区：容易犯的错误                     │
│  - 搭配模型：和哪些模型组合使用效果更好          │
├─────────────────────────────────────────┤
│  💡 一句话记忆卡片                          │
│  方便用户快速回忆的金句                       │
├─────────────────────────────────────────┤
│  📎 延伸阅读                               │
│  推荐书籍、文章、视频等                       │
└─────────────────────────────────────────┘
```

## 三、功能需求

### 3.1 核心功能（P0 — 首期必做）

#### 3.1.1 首页

- **Hero 区域**：品牌标语 + 搜索框 + 模型总数展示
- **精选推荐**：编辑精选的 6-8 个高价值模型卡片
- **分类导航**：以图标+文字形式展示所有分类入口
- **每日一模型**：每天随机/人工推荐一个模型，培养用户访问习惯
- **最近更新**：最新添加或更新的模型列表

#### 3.1.2 模型浏览与搜索

- **分类浏览**：按分类查看模型列表，支持切换网格/列表视图
- **全文搜索**：支持按模型名称、关键词、标签进行搜索
- **筛选排序**：
  - 按分类筛选
  - 按难度等级筛选（入门 / 进阶 / 高级）
  - 按热度、最新、推荐排序
- **标签系统**：每个模型可打多个标签（如 #决策 #投资 #管理 #心理学）

#### 3.1.3 模型详情页

- 完整展示 2.2 节定义的所有内容模块
- 侧边导航：快速跳转到页面各区块
- 相关模型推荐：底部展示 4-6 个关联模型
- 分享功能：生成精美的模型卡片图片，支持分享到社交平台

#### 3.1.4 模型图谱（知识图谱可视化）

- 以**力导向图/树状图**的形式展示所有模型之间的关联关系
- 点击节点可查看模型简介和跳转详情
- 支持按分类高亮筛选
- 支持缩放和拖拽交互

### 3.2 增强功能（P1 — 二期迭代）

#### 3.2.1 用户系统

- 注册/登录（邮箱 + 第三方登录）
- 个人主页
- 收藏夹：收藏感兴趣的模型
- 学习记录：已阅读/已掌握的模型追踪
- 学习笔记：在模型下添加个人笔记

#### 3.2.2 学习路径

- **场景化学习路径**：如"产品经理必备 10 个模型"、"投资决策思维体系"
- **难度递进路径**：从入门到高级的进阶路线
- 完成进度追踪

#### 3.2.3 互动功能

- 模型评分：用户给模型的实用性打分
- 案例投稿：用户提交自己的应用案例
- 评论讨论区

#### 3.2.4 测验与练习

- 每个模型配套 2-3 道情景选择题
- 完成测验后获得"已掌握"标记
- 定期复习提醒（基于艾宾浩斯遗忘曲线）

### 3.3 未来展望（P2）

- AI 助手：输入你的决策场景，推荐适合的思维模型组合
- 模型对比：选择 2-3 个模型进行横向对比
- 社区 UGC：用户可贡献新模型和案例
- 移动端 App / 小程序
- 多语言支持（英文版）

## 五、非功能需求

### 5.1 性能要求

| 指标 | 目标 |
|------|------|
| 首屏加载时间 | < 2 秒（3G 网络下 < 4 秒） |
| 搜索响应时间 | < 500ms |
| 图谱渲染 | 100 个节点流畅交互（60fps） |
| Lighthouse 评分 | Performance > 90, SEO > 95 |

### 5.2 SEO 要求

- SSR 或 SSG 渲染，确保搜索引擎可索引
- 每个模型页面有独立的 Meta 标题、描述、关键词
- 结构化数据标记（Schema.org）
- 自动生成 Sitemap
- 友好的 URL 结构（如 `/models/first-principles`）

### 5.3 响应式设计

- 完美适配：桌面端（1440px+）、平板（768px-1439px）、手机（< 768px）
- 移动端优先的交互设计

### 5.4 可访问性

- 符合 WCAG 2.1 AA 标准
- 支持键盘导航
- 图片提供 Alt 文本
- 足够的颜色对比度

## 六、技术方案建议

### 6.1 推荐技术栈

| 层级 | 技术选型 | 理由 |
|------|---------|------|
| 框架 | **Next.js 14+ (App Router)** | SSG/SSR 支持好，SEO 友好，React 生态丰富 |
| 样式 | **Tailwind CSS** | 开发效率高，响应式方便 |
| 内容管理 | **MDX 文件** (初期) / Headless CMS (后期) | 初期 Markdown 写作方便，后期可迁移到 CMS |
| 搜索 | **Fuse.js** (客户端) / **Algolia** (后期) | 初期轻量，后期可升级 |
| 图谱可视化 | **D3.js** 或 **react-force-graph** | 交互性强，社区活跃 |
| 部署 | **Vercel** | 与 Next.js 深度集成，自动 CI/CD |
| 数据格式 | **MDX + Frontmatter** | 内容与代码分离，易于维护 |

### 6.2 内容文件结构示例

```
content/
├── models/
│   ├── first-principles.mdx        # 第一性原理
│   ├── second-order-thinking.mdx    # 第二序思维
│   ├── inversion.mdx                # 反转思维
│   └── ...
├── categories/
│   ├── decision-making.json         # 决策思维分类信息
│   └── ...
└── paths/
    ├── product-manager.json         # 产品经理学习路径
    └── ...
```

```yaml

## 七、设计风格指南

### 7.1 整体风格

- **现代简约**：大量留白，信息层级清晰
- **知识感 + 温度感**：不是冰冷的百科，而是像一个聪明朋友在给你讲解
- **卡片化设计**：模型以卡片形式展示，视觉整洁有序

### 7.2 色彩方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#6C5CE7` (紫色) | 代表智慧与思考 |
| 辅助色 | `#00B894` (绿色) | 代表成长与实践 |
| 强调色 | `#FDCB6E` (金色) | 用于高亮和重点 |
| 背景色 | `#FAFAFA` | 柔和的浅灰白 |
| 文字色 | `#2D3436` | 深灰，阅读舒适 |

### 7.3 字体

- 标题：思源黑体 / Inter（英文）
- 正文：思源宋体 / 系统默认（保证阅读舒适度）
- 代码/标签：JetBrains Mono

### 7.4 模型卡片设计

```
┌──────────────────────────┐
│  🔬                      │
│  第一性原理                │
│  回归事物本质，从零开始推理   │
│                          │

│  ──────────────────────  │
│  别问别人怎么做，           │

## 十、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 内容创作周期长 | 上线内容不足 | 优先完成 20 个高频模型，后续持续更新 |
| 同质化竞争 | 用户选择其他平台 | 差异化：更好的可视化 + 案例 + 使用指引 |
| SEO 见效慢 | 早期流量不足 | 同步在社交媒体（小红书/公众号）分发内容引流 |
| 图谱性能问题 | 模型数量增多后卡顿 | 采用 WebGL 渲染，分级加载 |
